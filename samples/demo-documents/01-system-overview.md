# RAG 工作台系统概览

该系统面向个人和小团队的知识库问答场景，目标是让资料检索、引用来源、回答可信度和问题反馈都能被看见。默认演示模式使用 hash embedding 和模板回答，不依赖真实 API Key，也不会上传资料到外部服务。

## 核心流程

1. 上传 Markdown、PDF、文本或图片资料。
2. 后端完成文本解析、chunk 切分、去重和索引。
3. 查询时同时运行关键词检索和向量检索。
4. 对候选片段做去重、MMR 多样性选择和可选 rerank。
5. 生成答案时保留引用片段、分数、trace 和可信度审计。

## 设计目标

- 回答必须能追溯到原始资料。
- 检索失败要能看到 fallback 原因。
- 参数调试要能比较不同策略的召回结果。
- 负反馈可以沉淀成评测样本。
