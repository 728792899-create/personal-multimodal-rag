# AIGC 工作流资料摘录

AIGC 应用通常不只是一次模型调用，而是由输入理解、提示词编排、素材生成、结果校验、失败重试和人工编辑组成的工程流程。系统需要把中间结果保存下来，允许局部重试和回看。

## 工程能力

- 前端需要清楚展示任务状态、错误原因和可重试入口。
- 后端需要对不同 provider 做统一封装。
- 生成结果需要有结构化记录，方便后续复用。
- Demo 模式应能在无真实 Key 的环境下走通主流程。

## 常见风险

第三方模型失败、图片或音频生成超时、输出格式不稳定、素材版权不明确、长任务进度不可见，都会影响实际可用性。因此系统要有 fallback、日志、任务状态和边界提示。
