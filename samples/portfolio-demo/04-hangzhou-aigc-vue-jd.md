# 杭州 AIGC / Vue 岗位 JD 摘要

## 岗位方向

AIGC 应用开发工程师 / Vue 前端工程师 / AI 工具产品开发。

## 常见要求

- 熟悉 Vue 3、TypeScript、Vite 和组件化开发。
- 有前后端联调经验，理解 REST API、鉴权、状态管理和错误处理。
- 熟悉大模型应用开发，了解 Prompt Engineering、RAG、向量数据库、embedding、rerank。
- 能把 AI 能力做成真实产品功能，而不是停留在 Demo。
- 有良好的工程意识，包括测试、构建、部署、日志和性能优化。

## 加分项

- 有 RAG 或知识库问答项目经验。
- 能解释检索质量、引用可信度和幻觉控制。
- 有评测体系或数据闭环设计。
- 有复杂工作台 UI 或 Web 交互项目经验。

## 面试重点

面试官可能追问：

1. RAG 为什么需要混合检索？
2. 如何判断答案是否可信？
3. 搜不到资料时系统应该怎么处理？
4. 如何设计前端工作台的信息结构？
5. 如何把用户反馈变成下一轮优化？
