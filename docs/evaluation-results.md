## 数据集构成

- 总计 100 条：89 条可回答 / 11 条拒答。
- 从 40 条耐久本地版基线新增 60 条：12 图像、12 表格、8 公式、12 版面/OCR、10 多跳图谱、6 冲突/拒答。
- 12 张真实 PNG 固定样例在 `samples/multimodal-fixtures/images`；确定性图注/OCR 与结构化证据位于 `samples/demo-documents/07-*` 至 `12-*`。
- DOCX 案例仍从 JSON 规范生成 Office ZIP，并经过真实 DOCX 解析器；图谱案例经原生轻量图谱建图、路径查找和证据元素映射。
- 类别/来源分布由运行器从 JSONL 计算，不维护可漂移的人工计数表。

## 新指标如何判定

- 模态 Recall@5：图像、表格、公式和版面案例的目标证据是否进入前五。
- 表格单元、图注和公式：召回证据必须包含案例声明的确定性单元、图注词或规范化公式。
- 图谱路径精度：路径必须包含预期实体和关系；没有来源依据的路径不会进入评测输入。
- 图谱证据覆盖率：路径返回的元素 ID 必须被最终前五引用覆盖。
- 多跳 Recall@5：10 个两跳案例单独统计，避免被简单问题的总 Recall 掩盖。

## 判定边界

MRR 和首条引用没有被修饰成 1.0：少量旧案例的正确证据在前五但不在第一位。这正是保留真实数值的意义；阈值通过不等于无需案例级分析。

局限：

1. 固定样例和模板使结果确定，也让分布远小于真实业务。
2. 新多模态指标验证本项目中间表示/检索映射，不代表任意 OCR/VLM 的开放集准确率。
3. 哈希嵌入不代表生产语义嵌入；外部模型提供方需要独立版本化评测。
4. 仍需用真实业务的扫描件、长表格、多语言和冲突文档做人工标注外部集。
