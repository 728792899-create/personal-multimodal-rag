# 已知边界

## 候选版范围内

- 默认哈希/模拟嵌入是确定性离线替身，不代表真实语义向量质量；其拒答门会要求实质性词项证据。
- 模板回答主要用于可复现演示，不具备真实模型的综合表达能力。
- 演示模式的 SQLite + 本地文件 + 内存向量库适合单实例，不适合水平扩展；生产配置已提供 PostgreSQL/pgvector、S3/MinIO 和 Redis 适配器，但尚未完成仓库外真实容量与 14 天运行门。
- 进程内限流在多副本之间不共享；生产应移到网关或 Redis。
- 本地索引工作进程有 SQLite 事实源、租约与三次尝试，但仍是单进程执行器；多实例、优先级、死信队列和跨主机故障转移需要外部队列。
- 演示/本地模式的标准库 URL 路径仍主要用于可复现开发；生产模式强制使用无密钥、无数据卷的隔离抓取工作进程，对每次重定向重新解析并把连接固定到已验证公网 IP。
- 内置解析器已保留 PDF/DOCX 的有序元素、常见表格、公式、嵌入图片、边界框与可选 OCR，但复杂跨页表格、手写内容和任意版面仍可能需要隔离的 MinerU/Docling/PaddleOCR 配置；音频、视频与专用视觉嵌入尚未实现。
- 引用审计是透明的规则评估，不等同于人工事实核查或 NLI 判断器。

## 外部服务未完成项

- 本机 Ollama 的嵌入原生/兼容接口已真实通过，但 `qwen3:8b` 的原生聊天、OpenAI-compatible 聊天补全与 Responses 均在 180 秒超时；生产默认模型仍需按目标硬件重新选型。没有 OpenAI 云端凭据，也没有连接托管 OIDC 或 Sentry 项目。
- 当前是服务端解析的单工作区/单管理员边界；多工作区、OIDC/RBAC 与数据库 RLS 顺延到 1.1。
- GitHub Actions 已在远端实际运行后端、前端/端到端测试、检索评测和 Docker Compose 作业；后续每次合并仍需以对应提交的检查结果为准。
- 已在本机隔离生产栈执行一次破坏性恢复和五类故障注入；这不替代目标容量环境复演。14 天链已如实记录五次宿主机/容器运行时长间隔，最长连续窗口为 81,984 秒；`2026-07-27T10:10:58Z` 的真实 `TimeoutError` 已保留在链中，当前窗口自 `2026-07-27T10:16:11Z` 自然重置。人工标注、真实问题和真实语料质量基准仍未达标。
- Sentry SDK 与脱敏器已接入，但无 DSN，未验证真实事件；Docker 7.8 GiB 也不满足完整自托管配置的资源门。
- MinerU 高级解析真实 PNG 已通过；Docling/PaddleOCR 未安装，复杂 PDF/DOCX、GPU/内存峰值和质量仍需目标运行器验收。
