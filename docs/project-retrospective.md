# 项目复盘

## 背景

普通 RAG Demo 很容易停留在“上传文档、向量检索、调用模型回答”。这类实现能展示基础链路，但不容易定位错误发生在哪里：是文档解析失败、chunk 切分不合理、召回不准、排序错误，还是答案生成阶段产生了无证据推断。

本项目把 RAG 链路拆成多个可观察模块，并在前端展示引用、分数、trace、fallback 和可信度审计，方便调试和持续改进。

## 关键取舍

- 默认使用 hash/mock embedding，让项目在无 Key 环境下也能跑通。
- 把 Chroma、pgvector、真实 embedding 和 reranker 做成可选增强，避免默认启动过重。
- 保留专家模式，用于查看检索参数和策略对比。
- 保留普通模式，让常规问答路径不被工程参数干扰。

## 后续方向

- 增加更系统的离线评测集。
- 补充权限隔离和多用户资料空间。
- 对真实 embedding 与 reranker 做质量对比。
- 增强 OCR、表格和图片资料解析。
- 增加更细粒度的引用可信度评分。
