# 路线图

路线图按风险和验证价值排序，不按“功能数量”排序。默认离线演示模式必须一直可运行，新基础设施通过适配器增强，而不是成为仓库启动的前置条件。

## 已交付：0.1 候选版基线

- [x] 多格式上传、公开 URL 导入与可选 OCR。
- [x] BM25 + 向量检索 + 融合 + MMR + 重排。
- [x] 无证据拒答、引用上下文与引用审计。
- [x] 普通/专家模式、响应式布局和错误恢复。
- [x] 反馈生成评测草稿。
- [x] 30 条固定黄金集和四项 CI 阈值（0.2 已扩展）。
- [x] pytest、Vitest、Playwright、Docker Compose 健康检查。
- [x] 上传/URL 安全、限流、脱敏日志与可选 Sentry。

## 已交付：0.2 持久本地版

目标：让单用户长期使用时的数据、索引和升级更可靠。

- [x] 本地 sentence-transformer 嵌入配置（可选依赖）。
- [x] Chroma 集合的维度、模型和索引版本检查。
- [x] 分块器/嵌入/索引版本写入元数据，不兼容文档隔离为 `needs_rebuild`。
- [x] SQLite 任务、本地工作进程、租约恢复、幂等、取消与三次重试。
- [x] 多知识库、持久会话、稳定 SSE 与模型提供方状态。
- [x] DOCX 标题、段落、表格和 ZIP 炸弹防护。
- [x] 40 条固定黄金集、五项 CI 阈值及知识库/多轮/DOCX/版本案例。

退出条件：代码级重启恢复、迁移、维度门、失败重试和取消已有自动化证据；真实外部模型提供方/存储和人工备份恢复仍需部署环境验证。

## 当前：0.3 多模态智能

目标：把原件、版面元素、图片/表格/公式和图谱导航纳入可重建、可引用、可评测的同一证据模型，同时保持零 Key 默认路径。

- [x] 架构 v4 多模态元素、内容寻址对象存储、原件与派生资源生命周期。
- [x] PDF/DOCX 原始顺序、边界框/表格/图片与元素驱动分块；内置解析器继续零下载。
- [x] 隔离解析工作进程契约与 RAG-Anything `content_list` 适配器；高级镜像仅手动配置。
- [x] 递归、增量、并发受控的批量目录导入命令行工具。
- [x] 架构 v5 增强缓存、带来源证明的轻量图谱与 `hybrid_graph/auto`。
- [x] 上下文窗口、模板/Responses/兼容接口/Ollama 增强、重试与熔断。
- [x] 可配置父级上下文、模态过滤、图谱 RRF 和后端检索追踪契约。
- [x] 图片提问、元素查看器、图谱检索追踪与精确引用跳转。
- [x] 扩展至 100 条多模态黄金集和解析器/资源/图谱专项 CI。
- [x] 解析质量、OCR、图注、表格、公式和图谱覆盖仪表盘。

退出条件：对象/元素迁移与删除、解析回退/取消、图谱来源证明、图片提问、100 条固定集及浏览器普通/专家/窄屏验收均有真实自动化或人工证据。

## 当前候选版：0.4 本地生产 RC

目标：交付一个受支持的单管理员自托管运行路径，并用公开契约与私有真实证据明确区分 RC 和 1.0。

- [x] Argon2id 管理员会话、CSRF、撤销与服务端工作区上下文。
- [x] PostgreSQL 元数据/pgvector 适配器、SQLite 迁移与校验和对账。
- [x] S3-compatible 暂存对象、ClamAV 发布门与级联删除契约。
- [x] Redis Streams、事务发件箱、幂等工作进程、重试与死信队列。
- [x] 白名单目录、URL 列表、RSS/Atom 增量同步与安全删除候选。
- [x] 隔离抓取工作进程、逐跳 DNS 验证、IP 固定、大小与超时上限。
- [x] Prometheus、可选 OTLP/Sentry、Grafana 仪表盘、CodeQL/Trivy/SBOM/签名工作流。
- [x] 备份/恢复、故障注入和真实语料证据命令；默认保持安全试运行/阻断状态。
- [ ] 在参考硬件完成容量、恢复和 14 天稳定性运行；以私有证据清单通过全部 1.0 发布门。

退出条件：200 份非固定测试集文档、200 条人工标注、100 次真实问题、完整恢复演练、14 天真实部署、无数据丢失级缺陷，并达到 `docs/release-evidence-1.0.md` 的质量阈值。

## 后续版本：1.1 小团队版

- [ ] OIDC/OAuth2、RBAC 与真正的多工作区授权隔离。
- [ ] 多副本共享限流、并发/容量基线与高可用部署。
- [ ] Kubernetes、外部密钥管理器与托管对象/队列适配。
- [ ] Bilibili、Notion、Drive 等需稳定认证边界的连接器。

## 研究方向

- 多模态版面模型、表格结构恢复和图片语义嵌入；
- 父子检索与更细粒度引用跨度；
- 学习型稀疏检索和可插拔交叉编码器；
- NLI/LLM 判断器与人工抽样结合的引用评估；
- 查询分解、多跳检索和冲突证据呈现；
- 真实用户反馈采样、漂移检测和在线影子评估。

研究功能必须先定义离线替代、失败模式、成本上限和可量化验收，再进入默认路径。

## 明确不做

- 在没有工作区授权前宣称多租户隔离；
- 把默认哈希嵌入指标描述成真实语义检索效果；
- 让在线 LLM judge 成为唯一质量门；
- 为了提高 Recall 关闭拒答或引用检查；
- 把 API Key、共享令牌或数据库凭据编译进前端；
- 以破坏离线一键启动为代价增加外部依赖。
